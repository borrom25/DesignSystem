# Правила создания компонента

Этот шаблонный проект предназначен в первую очередь для реализации экранов из готовых компонентов `borrom-ds-test`. Новый компонент создавай только если в дизайн-системе действительно нет подходящей реализации.

## Перед созданием

1. Проверь `borrom-ds-test` и документацию компонента.
2. Проверь Figma Code Connect, docs и Git links.
3. Проверь соседние компоненты с похожим API.
4. Если компонент отсутствует, зафиксируй blocker и причину.

## Реализация fallback-компонента

Если пользователь согласовал fallback:

- снимай структуру по Figma layers/nodes через MCP;
- сохраняй auto-layout, constraints, fill/hug, variants и text styles;
- используй токены из `src/tokens` и `src/styles/global.css`;
- иконки бери из `lucide-react`;
- PNG используй только для визуальной проверки;
- все расхождения фиксируй как `Temporary mapping` / `Assumption`.

## Структура

Для локальных layout helpers используй:

```text
src/layouts/
src/pages/
src/shared/layout-recipes/
docs/layout-recipes/
```

Не создавай публичный UI-компонент, если задача решается page-level композициями и существующими компонентами DS.

## Проверка

Перед финалом:

```bash
npm run lint
npm run build
npm run encoding:check
```

После изменения зависимостей очисти Vite cache:

```powershell
Remove-Item -Recurse -Force node_modules/.vite
```
