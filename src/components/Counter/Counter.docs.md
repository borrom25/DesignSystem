## Figma to props mapping

| Figma property / variant | Figma values                     | Code prop           | Code values                    | Default  | Notes                                                                         |
| ------------------------ | -------------------------------- | ------------------- | ------------------------------ | -------- | ----------------------------------------------------------------------------- |
| `Text`                   | text                             | `count`             | `number`                       | required | Code Connect parses numeric text to `count`                                   |
| `Text` with `+` suffix   | e.g. `99+`                       | `count`, `maxCount` | `count={100}`, `maxCount={99}` | -        | Temporary mapping for capped values generated by `formatCount`                |
| `Size`                   | `Xs`, `Sm`, `Md`                 | `size`              | `xs`, `sm`, `md`               | `sm`     | Direct enum mapping to shared `Size`                                          |
| `Color`                  | `Accent`                         | `variant`           | `accent`                       | `accent` | Direct enum mapping                                                           |
| `Color`                  | `Neutral`                        | `variant`           | `neutral`                      | `accent` | Direct enum mapping                                                           |
| `Color`                  | `White`                          | `variant`           | `white`                        | `accent` | Direct enum mapping                                                           |
| Empty dot                | not exposed in Figma variant set | `empty`             | `boolean`                      | `false`  | Runtime supports it, Figma component set currently does not expose a property |

## Design matching notes

- Figma node `21178:1500` is a published component set named `Counter`.
- Figma variants cover all runtime `size` values and all runtime `variant` values.
- Runtime visual values come from tokenized styles in `src/components/Counter/styles`.
- Figma property `Text` is a string, while runtime `count` is a number. Code Connect parses it before generating JSX.
- `Counter` renders as a small inline badge for nested use in components such as `Button`, `Tab`, and menu/list items.

## Temporary mappings / assumptions

| Item                   | Current mapping                            | Reason                                                                | Follow-up                                                                         |
| ---------------------- | ------------------------------------------ | --------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Non-numeric `Text`     | fallback `count={1}`                       | Runtime API requires numeric `count`; arbitrary text is not supported | Keep Figma `Text` numeric or add a separate text badge component                  |
| `Text` with `+` suffix | `count={value + 1}`, `maxCount={value}`    | Runtime displays capped values through `formatCount(count, maxCount)` | Use this only for values intentionally shown as `N+`                              |
| Empty dot              | documented only, no Figma property mapping | Figma component set has no empty/dot boolean                          | Add `Empty` boolean in Figma if designers need Dev Mode snippets for dot counters |
